# Contributing

Contributions should teach one language idea without turning this repository into an
unstructured extension collection.

## Acceptance criteria

- The program prints exactly `Hello, polyglot world!` followed by a newline.
- The implementation is idiomatic for the language and uses no external dependency.
- The source lives under a meaningful paradigm or domain directory.
- `catalog.json` contains the language, family, path, run command, and expected output.
- The README atlas links the source and explains one idea worth noticing.
- `pwsh ./scripts/validate.ps1` passes.

Keep pull requests focused on one language or one infrastructure improvement.
